# HxD 16진수 분석 및 파일 비교

## 실습 도구
HxD, PEView

## 화면에서 확인한 내용
1. `TextView_Patch.exe`를 HxD로 열었다.
2. 시작 바이트 `4D 5A`(MZ 시그니처)가 확인됐다.
3. `Ctrl+G`로 파일 시작 기준 16진수 오프셋을 이동했다.
4. `0xF8`에서 `50 45 00 00`(PE 시그니처)을 확인했다.
5. `0x104` 위치까지 이동해 헤더를 확인했다.
6. 원본 `TextView.exe`와 복사본 `TextView_Patch.exe`를 HxD에 나란히 열었다.
7. `분석 → 데이터 비교` 메뉴를 열었다.

## 분석 시 주의
헤더의 특정 바이트 값은 파일 빌드에 따라 다를 수 있다. 문서에 기록된 주소와 값은 **이번에 관찰한 빌드** 기준이다. PE 패치나 DLL 주입의 성공은 단지 파일을 열거나 바이트를 확인하는 것만으로 판정할 수 없다.
